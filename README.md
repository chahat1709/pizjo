# ──────────────────────────────────────────────
# Pizjo Web
# Custom website + ordering experience for Pizjo,
# Amraiwadi, Ahmedabad.
# ──────────────────────────────────────────────

A single-page web app for Pizjo (pizjo.in), built with vanilla
HTML + CSS + JavaScript. Three.js exploded-pizza hero, WhatsApp
deep-link checkout, security-hardened input handling, Playwright
end-to-end test coverage.

## Tech stack

- HTML, CSS (multi-file), vanilla JS (ES modules)
- Three.js for the 3D pizza hero
- Playwright for end-to-end browser tests

## Status

Active development. Private repository — see LICENSE.txt.

## Local development

    open index.html

## Tests

    npm install
    npx playwright install chromium
    npm test
